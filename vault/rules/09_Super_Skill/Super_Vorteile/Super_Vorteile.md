# Übernatürliche Vorteile {#uebernatuerliche-vorteile}

Durch die Vorteile Zauberer/Geweihter erhält ein Charakter Zugang zu den folgenden übernatürlichen Vorteilen und Stilen.

## Gemeinsame Übernatürliche Vorteile {#gemeinsame-uebernatuerliche-vorteile}

Die folgenden Vorteile können mit dem Vorteil Zauberer und Geweihter gekauft werden. Sie stellen Überschneidungen zwischen den beiden Repräsentationen von Energie dar.

## Zauberer Vorteile

Die folgenden Vorteile können nur mit dem Vorteil Zauberer gekauft werden. Sie stellen Besonderheiten dieser Energierepräsentation dar.

## Geweihter Vorteile

Die folgenden Vorteile können nur mit dem Vorteil Geweihter gekauft werden. Sie stellen Eigenheiten dieser Energierepräsentation dar.
