## Übernatürliche Vorteile

<a id="uebernatuerliche-vorteile"></a>

Durch die Vorteile Zauberer/Geweihter erhält ein Charakter Zugang zu den folgenden übernatürlichen Vorteilen und Stilen.

- [Uebernatuerliche Stile](Uebernatuerliche_Stile.md)

### Gemeinsame Übernatürliche Vorteile

<a id="gemeinsame-uebernatuerliche-vorteile"></a>

Die folgenden Vorteile können mit dem Vorteil Zauberer und Geweihter gekauft werden. Sie stellen Überschneidungen zwischen den beiden Repräsentationen von Energie dar.
- [SV FF](gemiensame_vorteile/SV_FF.md)

- [SV KO](gemiensame_vorteile/SV_KO.md)

### Zauberer Vorteile

<a id="zauberer-vorteile"></a>

Die folgenden Vorteile können nur mit dem Vorteil Zauberer gekauft werden. Sie stellen Besonderheiten dieser Energierepräsentation dar.
- [ZV CH](zauberer_vorteile/ZV_CH.md)

- [ZV IN](zauberer_vorteile/ZV_IN.md)

- [ZV KL](zauberer_vorteile/ZV_KL.md)

- [ZV MU](zauberer_vorteile/ZV_MU.md)

### Geweihter Vorteile

<a id="geweihter-vorteile"></a>

Die folgenden Vorteile können nur mit dem Vorteil Geweihter gekauft werden. Sie stellen Eigenheiten dieser Energierepräsentation dar.
- [GV CH](geweihten_vorteile/GV_CH.md)

- [GV IN](geweihten_vorteile/GV_IN.md)

- [GV KL](geweihten_vorteile/GV_KL.md)

- [GV MU](geweihten_vorteile/GV_MU.md)
