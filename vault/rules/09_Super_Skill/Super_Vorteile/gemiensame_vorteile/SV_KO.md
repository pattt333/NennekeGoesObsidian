| **Zauberer I/Geweihter I** |  |

| **Zauberer I/Geweihter I** |  |
| **60EP** | **Meditation** Du fügst dir bis zu 4 Wunden zu. Für jede dieser Wunden kannst du WS+4 Energie regenerieren. Du kannst verbotene Pforten immer einsetzen, nicht nur, wenn du keine Energie mehr hast. Einmal pro Ruhephase nutzbar. Mit dem Vorteil verbotene Pforten regenerierst du sogar WS+6 Energie |
| **Attribut 10** |  |
| **Zauberer I/Geweihter I** |  |
| **80EP** | **Mächtiger Astralkörper** Deine Energie erhöht sich um 2*KO. |
