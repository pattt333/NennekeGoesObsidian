## Fernkampf

Fernkampfangriffe (FK) führt man in mehreren Schritten aus:
1. Auswahl der Modifikationen: Du gibst zu [Beginn der Kampfrunde](06_Kampf.md#sub-inisystem) an mit welchen Modifikationen du diesen Angriff ausführst (am besten fluffig ausgedrückt), denn diese können deinen INI-Modifikator vorgeben.
1. Danach würfelst du deine INI aus
1. Bis du an der Reihe bist, führt dein Charakter die [Aktion Konzentration](06_Kampf.md#sec-aktionen) aus. Dabei kommen alle Regeln für die Konzentration zum Einsatz.
1. Wenn du an der Reihe bist, wählst du ein Ziel in Reichweite
1. Probe: Zuletzt würfelst du eine Probe auf die Fernkampf-Fertigkeit, zu der deine Waffe gehört. Diese Probe wird gegen eine Schwierigkeit von 12.

Genau wie Nahkampfangriffe werden auch Fernkampfangriffe durch die Umgebung modifiziert, zum Beispiel durch die Größe und Bewegung des Ziels. Bei einer Bewegung des Ziels zählt immer die Grund GS des Ziels als Kategorisierung (schnell, sehr schnell, extrem schnell) (auch wenn es Buffs hat, die im Nachhinein die GS erhöhen (z.B. Axxeleratus)). Eine Ausnahme stellen Wesen mit dem Vorteil Paraphysikalität dar. Diese sind nicht an physikalische Einschränkungen gebunden und können auch etwaige Bonusse beachten, wenn ihre Kategorie bestimmt wird.

Der Meister sollte in fast allen Situationen Umgebungsnachteile verteilen. Zum Beispiel sollte ein Innenraum bei Tag oder ein Wald schon als eingeschränkte Sicht zählen. Sobald im Offenen gekämpft wird sollte ein Nachteil für Wind bestehen, außer es herrscht durch übernatürliche Umstände Windstille.

| **Modifikatoren im Fernkampf (Beispiele)** |  |  |  |
| --- | --- | --- | --- |
| **Untergrund** | **Sicht** |  |  |
| Unsicherer Untergrund (knietiefes Wasser) | -4 | eingeschränkte Sicht | -4 |
| Schwieriger Untergrund (hüfttiefes Wasser) | -8 | schlechte Sicht | -8 |
| Sehr schwieriger Untergrund (unter Wasser) | -12 | sehr schlechte Sicht | -16 |
| Nahezu unpassierbarer Untergrund | -16 | Dunkelheit | Glückstreffer |
| **Größenklasse des Ziels** | **Umgebung** |  |  |
| Riesig (Drache, Riese) | +8 | Leichte Brise | -2 |
| Groß (Pferd, Oger) | +4 | Starke Böe | -4 |
| Mittel(Mensch, Elf, Zwerg) | 0 | Sturm | -8 |
| Klein (Wolf, Reh) | -4 |  |  |
| Sehr Klein | -8 |  |  |
| Winzig (Kröte, Spatz) | -12 |  |  |
| **Bewegung** | **Sonstiges** |  |  |
| Schnell (laufender Mensch; GS 1-7) | –4 | Halbe Deckung | -4 |
| Sehr Schnell (Pferd; GS 8-12) | -8 | Dreivierteldeckung | -8 |
| Extrem Schnell (fliegender Vogel; GS >= 13) | -16 | Berittener Schütze | -4 |

<a id="subsec-schusseinkampf"></a>

### Schüsse in Nahkämpfe

Bei Schüssen in Nahkämpfe (2 oder mehr Kontrahenten) steigt die Chance einen Verbündeten zu treffen enorm. Die Patzerchance bei Schüssen in Nahkämpfe hängt von der Art ab. Sie steigt um zusätzliche -2/-4 in [Duell/Kampfgetümmel](Angriff_Verteidigung.md#subsec-reichweite).

<a id="subsec-reichweitefernkampf"></a>

### Reichweite von Fernkampfwaffen

Wie Nahkampfwaffen besitzen Fernkampfwaffen ebenfalls eine Reichweite. Bei jeder Fernkampfwaffe ist jeweils eine Reichweite angegeben. Diese Reichweite kann die Waffe unter normalen Umständen nicht überschreiten. Mit Manövern kann die Reichweite jedoch modifiziert werden.

<a id="subsec-verteidigungfernkampf"></a>

### Verteidigung gegen Fernkampfangriffe

Wenn ein Charakter einen Schützen beim Zielen beobachtet, kann er eine Verteidigung gegen den Fernkampfangriff ausführen. Dazu muss er eine Reaktion aufwenden Schild-VT (28, I) oder Athletik (Ausweichen)-Probe (28, I) ablegen. Befindet sich der Schütze im Kontrollbereich des Charakters, genügt eine freie Aktion, um seine Waffe beiseite zu schlagen.

<a id="subsec-patzer-im-fernkampf"></a>

### Patzer im Fernkampf

Wann immer dir ein Fernkampfpatzer unterläuft, musst du 2W6 auf die Patzertabelle werfen.
| **2W6** | **Auswirkung** |
| --- | --- |
| **2** | Du erhältst einen Stack Blutung |
| **3** | Du verbrauchst doppelt so viel Munition |
| **4-8** | Fehlschuss, du musst deine Waffe mit einer Aktion Bereit machen. |
| **9-11** | Ein Verbündetes Ziel in Reichweite (vom Spielleiter gewählt oder nächstes Ziel in der Schusslinie) erleidet die Hälfte deines normalen Waffenschadens (aufgerundet). Falls keines vorhanden ist, verfehlt der Schuss knapp deinen eigenen Fuß. |
| **12** | Du erleidest deinen Waffenschaden. |
