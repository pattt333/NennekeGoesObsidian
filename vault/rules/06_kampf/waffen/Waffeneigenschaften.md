<a id="subsec-waffeneigenschaften"></a>

### Waffeneigenschaften

<a id="wf-einschuchternd"></a>

**Einschüchternd:** Beeinflussung (Einschüchtern)-Probe um X erleichtert. Z.b. einschüchternd (2) = Beeinflussung (Einschüchtern)-Probe um +2 erleichtert.

<a id="wf-fernkampfoption"></a>

**Fernkampfoption:** Die Waffe hat eine Fernkampfoption in Klammern ist der Name der Fernkampfoption angegeben.

<a id="wf-feuerwaffe"></a>

**Feuerwaffe:** Die Waffe verursacht bereits bei einer 3 einen Patzer, jedoch auch bei einer 19 bereits einen kritischen Treffer.

<a id="wf-grossewaffe"></a>

**Große Waffe:** Bei Seeschlachten oder Feldschlachten werden große Waffen verwendet. Entitäten in dieser Skalierung können nur von Waffen mit dieser Eigenschaft beschädigt werden. Umgekehrt können diese Waffen nicht im normalen Kampf eingesetzt werden (sie sind einfach zu langsam und träge um effektiv gegen einzelne mittel große Gegner eingesetzt zu werden)

<a id="wf-haken"></a>

**Haken:** Umreißen/Niederwerfen um +2 erleichtert.

<a id="wf-hilftbei"></a>

**Hilft bei (Fertigkeit):** das Tier ist zählt als große Hilfe (+4 auf deine Probe) bei der angegeben Fertigkeit.

<a id="wf-improvisiert"></a>

**Improvisiert:** Die Waffe ist improvisiert (nur wichtig für die Streuner Vorteile [Streuner](../../07_vorteile/kampf_vorteile/STREUNER.md#kv-streuner)).

<a id="wf-kopflastig"></a>

**Kopflastig:** Die Waffe kann zusätzliche Kraft besonders effizient in Schaden umwandeln. Der Schadensbonus durch hohe KK zählt für sie doppelt.

<a id="wf-ladezeit"></a>

**Ladezeit:** Die Waffe benötigt Zeit zum Laden. Waffen mit dieser Waffeneigenschaft verschieben dich immer in die nächste KR. Ausnahme ist der erste Schuss im Kampf, sofern die Waffe zu Kampfbeginn bereits im geladenen Zustand war.

<a id="wf-leicht"></a>

**Leicht:** Die Waffe erhöht deine INI um den +X, wenn du sie für einen Angriff verwendest.

<a id="wf-messerstecherei"></a>

**Messerstecherei:** Waffen mit dieser Eigenschaft verursachen in Kampfgetümmel Nahkämpfen +1W6 TP. Zusätzlich bei Fernkampfwaffen mit dieser Eigenschaft beträgt die Patzerchance für Schüsse ins Kampfgetümmel nur -1/-2 in Duellen/Kampfgetümmeln.

<a id="wf-phalanx"></a>

**Phalanx:** Waffen mit dieser Eigenschaft sind dazu in der Lage über/neben einem anderem Charakter vorbeizustechen, um damit einen anderen Charakter zu treffen. Das heißt, wenn ein Verbündeter vor dir steht, kannst du effektiv über 2 Felder (= RW2) hinweg angreifen.
Ein Charakter, der eine solche Waffe als Hauptwaffe führt, zählt nicht (= wird nicht berücksichtigt), wenn es darum geht zu bestimmen, ob ein Nahkampf ein Kampfgetümmel ist oder nicht.

<a id="wf-parierwaffe"></a>

**Parierwaffe:** Das Führen einer solchen Waffe ist Voraussetzung für den Parierwaffenstil.

<a id="wf-reittier"></a>

**Reittier:** Ein Reittier ist Voraussetzung für den Reiterkampfstil. Angriffe mit dem Reittier sind um +4 erleichtert, wenn das Reittier in einer höheren Größenklasse als das Ziel ist.

<a id="wf-rustungsbrechend"></a>

**Rüstungsbrechend:** Ein schmaler Stoßdorn oder andere Waffenteile können Rüstungen durchschlagen. Ermöglicht das Manöver Rüstungsbrecher.

<a id="wf-schild"></a>

**Schild:** Ermöglicht den Kampf im Schildkampfstil. Verteidigungen mit einem Schild sind um +4 erleichtert, wenn der Angreifer in einer höheren Größenklasse ist. Ein Schildträger kann sowohl Angriffe von Tieren und größeren Gegnern parieren, als auch Fernkampfangriffe. Schilde bieten dem Träger Halbe Deckung (Fernkampfangriffe -4).

<a id="wf-schusswaffe"></a>

**Schusswaffe:**
Die Waffe verursacht auch bei einer 2 einen Patzer.

<a id="wf-schwer"></a>

**Schwer:** Diese Waffe verringert deine INI um -X, wenn du sie für einen Angriff verwendest.

<a id="wf-stumpf"></a>

**Stumpf:** Die Eigenschaft ermöglicht das Manöver [Stumpfer Schlag](../kampfmanover/Basismanover.md#subsubsec-stumpferschlag)

<a id="wf-unberechenbar"></a>

**Unberechenbar:** Die Waffe verursacht auch bei einer 2 einen Patzer. Dafür kann sie auch um Schilde herumschlagen, was die Angriffe gegen Schildkämpfern um +2 erleichtert.

<a id="wf-unzerstorbar"></a>

**Unzerstörbar:** Die Waffe ist nur durch extreme Hitze, Magie oder andere extreme Schadensarten kaputt zu bekommen.

<a id="wf-wendig"></a>

**Wendig:** Die Waffe ist ungewöhnlich wendig, der erste Passierschlag in einer KR kann als freie Aktion ausgeführt werden.

<a id="wf-zerbrechlich"></a>

**Zerbrechlich:** Die Waffe ist fragil oder einfach nicht so richtig zum Kämpfen geeignet. Bei einem Patzer oder kritischen Treffer, wird die Waffe unbrauchbar und ist entweder zerstört (zb improvisierte Waffen) oder komplett unbrauchbar für den Rest des Kampfes geworden (wenn die Waffe nicht improvisiert ist).

<a id="wf-zweihandig"></a>

**Zweihändig:** Die Waffe benötigt die Führung mit beiden Händen. Bei einhändiger Führung erleidest du einen Malus von -2 und die Waffe richtet -4 TP weniger an.
