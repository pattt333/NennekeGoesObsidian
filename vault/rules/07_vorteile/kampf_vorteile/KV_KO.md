### KO-Vorteile

| **Voraussetzung** | **KO** |
| --- | --- |
| **Attribut 4** |  |
| **20EP** | **Zäher Hund** Proben gegen Wundschmerzeffekte sind nicht um die Wundabzüge erschwert. |
| **Attribut 6** |  |
| **40EP** | **Belastungsgewöhnung I** Die BE, die du durch die Anzahl deiner Rüstungspunkte erhältst, sinkt um 1. |
| **Attribut 8** |  |
| **60EP** | **Eisern** Wundeffekte treten bei dir nur beim Verlust von 3*LAW LeP auf einen Schlag auf, statt schon bei 2*LAW auf einen Schlag. |
| **Attribut 10** |  |
| **80EP** | **Belastungsgewöhnung II** Die BE, die du durch die Anzahl deiner Rüstungspunkte erhältst, sinkt um 2 weitere Punkte. |
