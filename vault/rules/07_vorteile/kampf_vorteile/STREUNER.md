### Streuner

| **Voraussetzung** | **Vorteil** |
| --- | --- |
| **40EP** | **Gassenkünstler** Wenn du eine improvisierte Waffe aus deiner Umgebung verwenden willst, kannst du diese in einer Aktion Bereit machen (einfach) ausrüsten, hier dürfen nur Waffen mit der Waffeneigenschaft [Improvisiert](../../06_kampf/waffen/Waffeneigenschaften.md#wf-improvisiert) gewechselt werden KEINE normalen Waffen (Kampfstil ist normal möglich). Ist die Aktion Bereit machen bereits für dich eine einfache Aktion, entfällt die Erschwernis beim kombinieren von Aktionen. |
| **50EP** |  |
| **Gassenkünstler** | **Meister improvisierter Waffen** [Improvisierte](../../06_kampf/waffen/Waffeneigenschaften.md#wf-improvisiert) Waffen, die du führst erhalten +2/+2, bis zu einem Gesamtmaxiumum von +2 (Bsp eine Waffe mit -4/-4 hat dann -2/-2, eine Waffe mit -4/1, hat dann -2/+2). Du kannst einer [improvisierten](../../06_kampf/waffen/Waffeneigenschaften.md#wf-improvisiert) Waffen eine der folgenden Waffeneigenschaften geben: [Kopflastig](../../06_kampf/waffen/Waffeneigenschaften.md#wf-kopflastig), [Wendig](../../06_kampf/waffen/Waffeneigenschaften.md#wf-wendig), [Stumpf](../../06_kampf/waffen/Waffeneigenschaften.md#wf-stumpf), [Parierwaffe](../../06_kampf/waffen/Waffeneigenschaften.md#wf-parierwaffe), [Haken](../../06_kampf/waffen/Waffeneigenschaften.md#wf-haken), Umklammern (12,-2) |
| **60EP** |  |
| **Meister improvisierter Waffen** | **Meister der urbanen Kriegskunst** [Improvisierte](../../06_kampf/waffen/Waffeneigenschaften.md#wf-improvisiert) Waffen , die du führst erhalten weitere +3/+3, bis zu einem Gesamtmaximum von +2 (Bsp: -2/-2, wird 1/1, -2/+2 wird 0/+2) Jede improvisierte Waffe, die du führst erhält außerdem die Waffeneigenschaft [Fernkampfoption (Improvisierte Wurfwaffe)](../../06_kampf/waffen/Waffeneigenschaften.md#wf-fernkampfoption), falls sie diese nicht schon besitzt oder selbst bereits eine Fernkampfwaffe ist. |
