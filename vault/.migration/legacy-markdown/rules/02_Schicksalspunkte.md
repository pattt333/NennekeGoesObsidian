# Schicksalspunkte

Schicksalspunkte kannst du erst einmal auf 5 Arten nutzen:

1.  Glückliche Fügung: Du kannst einen Schicksalspunkt einsetzen, der dir einen zusätzlichen Würfel für die nächste Probe verleiht. Statt drei Würfeln würfelst du vier und der zweithöchste Wert zählt. Statt einem Würfel würfelst du zwei und der höchste Wert zählt. Hierbei können niemals Patzer entstehen!

2.  Nur ein Kratzer: Unmittelbar nachdem du Schaden erlitten hast, kannst du einen Schicksalspunkt einsetzen. Dadurch werden die gerade erlittenen Wunden halbiert. Hierbei wird ausnahmsweise abgerundet.

3.  Von der Schippe springen: Du kannst 1 Punkt deines Schip-Startbetrags aufwenden, um den Tod deines Charakters abzuwenden. Du startest also von nun an jedes Abenteuer mit 1 Schip weniger, als bisher. Dazu musst du deinem Spielleiter einen plausiblen Vorschlag machen, wie dein Charakter die tödliche Situation überlebt. Von der Schippe springen lässt deinen Charakter übrigens nicht ungeschoren davonkommen. Eher überlebt er einen eigentlich tödlichen Sturz schwer verletzt oder wird von den Feinden für tot gehalten und ausgeplündert.

4.  Eine Probe nachträglich verbessern: Für einen Schicksalspunkt kannst du eine gewürfelte Probe einmal um +4 verbessern.

5.  Eine Probe wiederholen: Für einen Schicksalspunkt kannst du eine Probe wiederholen
