## Why

The converted vault is complete but still reads like a source tree: its home page only lists chapters, the Docsify sidebar exposes every source note, and opening the repository in Obsidian also exposes contributor tooling. Readers need a simple, German-language path from installation to looking up a rule during play.

## What Changes

- Add a vault-local Obsidian configuration so opening `vault/` provides the rulebook as the reader's workspace, with the useful built-in navigation features enabled and personal workspace state excluded from Git.
- Rework the generated rulebook navigation into a reader-first home page and a concise, hierarchical Docsify sidebar rather than an exhaustive flat source-note list.
- Generate stable parent, child, and previous/next navigation for source-derived rule notes from the LaTeX include tree, using links that work in both Obsidian and Docsify.
- Replace the root `README.md` with a German setup and reading guide that explains opening the vault, using the start page, search, outline, previews, bookmarks, and the optional Docsify view.
- Preserve the authoritative ZIP workflow: navigation is generated by the existing pipeline and does not turn rule content into manually maintained duplicates.

## Capabilities

### New Capabilities

- `reader-first-rulebook-navigation`: Readers can enter the rulebook through a concise home page and move between chapters, sections, and adjacent notes without browsing raw source paths.
- `obsidian-rulebook-setup`: Readers can open the rulebook directory as an Obsidian vault and follow a German setup guide without exposing or committing personal workspace state.

### Modified Capabilities

- None.

## Impact

- Affected vault navigation: `vault/index.md`, `vault/_sidebar.md`, and generated Markdown rule notes under `vault/rules/`.
- Affected tooling: `scripts/nenneke_v2_pipeline.py` will generate reader navigation from the source include graph.
- Affected Obsidian configuration: a minimal shared configuration is added under `vault/.obsidian/`; root-level personal state is not moved or committed.
- Affected documentation: root `README.md` becomes a German reader setup guide; existing contributor/deployment documentation remains available under `docs/`.

## Validation Impact

- Run the conversion tests and validation to confirm regenerated navigation remains source-backed.
- Run `npm run validate:links` and `npm run validate:orphans` after changing navigation.
- Preview the Docsify home page, sidebar, a chapter page, and a nested rule note.
- Review the vault-local Obsidian configuration and German setup instructions; no end-to-end test automation is added.
